## 1. The Gate 0 question

```txt
Does a well-defined, gauge-invariant, informative holonomy exist on the
medial hub under the octonionic (Moufang) carrier algebra?
```

Three load-bearing words, each a separate proof obligation:

```txt
WELL-DEFINED:   the holonomy of a loop must not depend on arbitrary
                bracketing. Octonions are non-associative; a loop product
                of n>2 link variables has multiple bracketings differing
                by associators (A0's residues, relocated here). Either the
                value is bracketing-INVARIANT for the loop classes used
                (by theorem), or a bracketing POLICY is declared and its
                gauge-invariance proven. Convention is not physics unless
                proven gauge-stable.

GAUGE-INVARIANT: the holonomy observable must be stable under the declared
                gauge action. The minimum gauge orbit is the predecessor's
                7x24 = 168 Fano quadrangle labelings; the model card must
                also DECLARE the site-local gauge action (the lattice-gauge
                analog of U_ij -> g_i U_ij g_j^{-1}) appropriate to the
                carrier algebra, and state which transformations are gauge
                and which are physical.

INFORMATIVE:    a holonomy that is constant across all configurations is
                well-defined and empty. The observable must DISTINGUISH:
                its value must vary across structured controls (permuted /
                randomized link assignments) while being stable on the true
                configuration. A constant-everywhere observable fails Gate 0
                as surely as an ill-defined one.
```

## 2. Mathematical leads (to be tested, not assumed)

```txt
LEAD 1 — diassociativity / Artin: octonions are an alternative algebra; by
  Artin's theorem the subalgebra generated by any TWO elements is
  associative, and unit octonions form a Moufang loop (diassociative).
  Consequence to test: loop classes whose link variables lie in a
  2-generated subloop have bracketing-independent holonomy BY THEOREM.
  Identify which hub loop classes (triangles, squares, hexagonal
  great-circle cycles) satisfy this, if any.

LEAD 2 — explicit bracketing sensitivity: for the loop classes that are NOT
  2-generated, compute ALL bracketings (2 for triangles, 5 for squares, 42
  for hexagons) across the full gauge orbit and classify: invariant value /
  invariant class (e.g., up to sign) / genuinely bracketing-dependent.
  The predecessor's Bench-2 computed LEFT-ASSOCIATED products only; Gate 0
  must show what left-association hid or confirm it hid nothing.

LEAD 3 — the invariant function: for unit octonions the conjugacy-class /
  real-part analog of the Wilson trace must be DECLARED as the observable
  (raw loop products are gauge-covariant, not invariant). Which function of
  the holonomy is the observable is part of the model card, not an
  afterthought.
```
