## 0. What kind of plan this is

Three tests define this document:

```txt
1. It spans the full midterm ring. It ends in a VERDICT on
   field-layer generalizability, not in the next diagnostic.

2. It is the thing human and agent return to between branches
   to answer: where are we, what closes this station,
   what are we forbidden to do here.

3. It contains its own failure exits, so that if the field layer
   cannot generalize, the campaign exits honorably instead of grinding.
```

A plan that only elaborates Phase 3 would be short-term in disguise. A plan that promises the ultimate workspace would be vision cosplay. This plan sits between.

---

## 1. Destination

At the end of this campaign exactly one of the following is true, ratified by diagnostic evidence and a closing governance memo:

```txt
Verdict A — foundational:
  A generalized carrier-field stack runs operationally beyond the
  tetra first-birth instance, survives source-state and tuple
  reduction, demonstrably improves generated-site reading through
  FieldCueV0, and has a contracted 3D field-map target.

Verdict B — bounded local law:
  The carrier policy is real but provably hub-local. The field layer
  is preserved as a bounded instrument with explicit boundaries, and
  S0 / legibility work proceeds against those boundaries.

Verdict C — demoted:
  The field layer fails generalization tests and is archived as a
  local experiment. The project re-centers on legibility without
  field sovereignty.
```

All three are successful completions of this plan.

The only failure mode is the unresolved middle: an open-ended accumulation of diagnostics with no verdict. This plan exists to make that outcome impossible.

Each station declares: the question it answers, the work, the exit criteria, and its failure exit. Stations may not be skipped. A station is closed only by evidence plus a committed governance memo.

### Station III — Operational medial-hub test (Phase 5)

The center of gravity. The hardest station and the one most tempting to shrink.

Question:

```txt
Can the C0→G0 chain be RUN, not renamed, on the second instance
under the medial-dual carrier policy?
```

Work: carrier assignment → local channels → emissions → carrier graph field → spatial support → generational update for the chosen instance, with the stress conditions of the crisis handoff in force:

```txt
source count not equal to 4;
multiple possible birth paths;
carrier collisions handled as policy, not accident;
nontrivial support geometry.
```

Exit / Decision D3 — the verdict point of the campaign:

```txt
hub law confirmed        → continue to Station IV
policy revision needed   → one bounded revision loop, then re-test once
structural failure       → Verdict B or C; campaign closes honorably
```

Anti-trap rule: fake abstraction is an automatic station failure. If the second instance passes because tetra assumptions were renamed rather than re-derived, the pass is void regardless of diagnostic counts.

### Station IV — FieldCueV0 proof surface (Phase 6)

Question:

```txt
Does the generalized stack actually help a human read generated
sites — the project's original promise?
```

Work: adapt FieldCueV0, then GeneratedSiteReadingV0, to consume the generalized source-state truthfully, preserving multi-projection honesty and reduction statuses. The long-standing blockade on these two witnesses lifts here, and only here.

Exit / Decision D4 — the human-fruit test: the human, not a diagnostic, judges whether generated-site readings improved. If the field is generalizable but useless for reading, that is Verdict B material and must be recorded, not papered over.

### Station V — 3D field-map target (Phase 7)

Work: contract first, render second.

```txt
1. A display contract: what may be rendered, what statuses must be
   surfaced, no tuple-as-signature leakage, no outrunning
   diagnostic truth.

2. One bounded renderable field-map of the proven instance(s)
   matching that contract.
```

The only station where UI work is permitted.

Exit: contract committed, minimal render matching it, Verdict A ratification memo.

## 3. Standing rules for the whole campaign

Frozen throughout, regardless of station:

```txt
no S0
no topology workspace
no packet writing
no Shape mutation
no operation registration
no new route/gate/support/region feature families
no general algebra infrastructure
no field atlas replacement (except as Station III/IV evidence requires)
no universal-law language beyond tested scope
no UI before Station V
```

Branch budget: each station is roughly 1–4 narrow branches plus its closing memo. If a station wants a fifth branch, stop and return to this plan; that is the drift signature.

Two structural tests apply at every audit:

```txt
mock-solution test:
  Would this diagnostic still pass if the formal object under test
  were removed? If yes, the diagnostic is fake.

count-vs-structure test:
  Do the counts pass while the structure is flattened?
  (Precedent: the F1 complement transport bug.)
```

Memo discipline: every station closes with a governance memo committed to `docs/governance/`. This plan is amended there too — never silently contradicted. Repo code remains the factual authority for what exists; this plan is the authority for what each result means for the campaign.

Hard-problems registry: these three travel with the campaign and must receive an explicit status at the named stations, even if that status is "still open, bounded thus":

```txt
cube primal sourcehood             → status due at Station II
deeper-generation bracketing law   → status due at Station III
survival through propagation       → status due at Station IV
  (the Gate C.4 shadow: structure existing upstream
   does not mean structure surviving downstream)
```

Audit discipline (unchanged from prior handoffs): no commit before audit; no audit without diff; no diff without untracked-file handling; exact file staging only; never `git add .`; Codex prompts declare allowed files, forbidden files, expected diagnostics, expected statuses, do-not-commit, final `git status --short`.

## 4. Operating protocol for human and agents

At the start of any work step, declare:

```txt
current station;
current branch;
what evidence closes the station.
```

Re-entry ritual after any gap or for any new agent:

```txt
1. read this plan;
2. check git log against the station map;
3. reconcile (which stations have closing memos? which diagnostics exist and pass?);
4. only then move.
```

Plan check: either the human or any agent may call one at any time. The question "which station are we in and what closes it?" must always have a one-sentence answer. If it does not, the run has drifted: stop, reconcile against this plan, then continue.

A future agent encountering work that contradicts this plan should treat the contradiction itself as the first thing to surface — not silently follow the newer work, and not silently enforce this plan against an amendment it has not read. Find the amendment memo or flag the gap.
