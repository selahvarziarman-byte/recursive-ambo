```txt

(cuboctahedral / 12-flag) capsule in which the medial-dual carrier
policy's distinguishing content — signed Fano lifts, triangle closure,
square holonomy, ordered flag identity — actually instantiates as
```

This is a schema EXTENSION, not a rescue. If the fiber cannot instantiate honestly even in a capsule built for it, that is a finding of the highest campaign value and must be reported as such.
