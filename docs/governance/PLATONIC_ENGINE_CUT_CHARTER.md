## Why this is more than a tidy

Every operation so far has been an **identification** → `UNFAITHFUL` (heterogeneity) → `interior`. `cut` is the first **removal**, and it fires the two members nothing has touched on real material yet:
- **FAITHFUL by logging** — a *logged* loss certifies FAITHFUL (the first faithful real result; the zoo was all UNFAITHFUL).

With the zoo, `cut` closes **both faithfulness clauses** (heterogeneous-merge + logged/silent-loss) and **both manifold valences** (interior + boundary) on real material. Only the junction valence remains untested — and that one genuinely needs the cascade. So this is the substantive completion of the atomic operation set, not housekeeping.
