# THE LAW — A GUARD MUST NOT REQUIRE A HOLE IN ITSELF TO PERMIT A SANCTIONED CHANGE.
# A guard’s job is not to prevent change — it is to make change VISIBLE and
# DELIBERATE. The old per-diagnostic HEAD-differential guards could permit a
# mandated edit only by removing the file from their own lists: every sanctioned
# change punched a silent, permanent hole (playgroundOperations.ts — the op
# registry, resolveLineage, getDisabledReason, singleFaceGateReason — ended up
# guarded by NOBODY, and nothing went red). This manifest replaces that mechanism:
#
#   · ONE frozen set, hashed by content: `<path>  <sha256 of CR-STRIPPED content>`.
#   · A SANCTIONED change to a frozen file updates its hash line HERE, in the
#     SAME commit — one loud, reviewable diff line. Coverage never lapses.
#   · NO CARVE-OUTS, EVER. A file never leaves this list to permit an edit.
#   · The checker (scripts/lib/engineFreeze.cjs) READS this file and can never
#     write it. No auto-regeneration, no --update, no fix mode. A hash update
#     is a deliberate human act, reviewed in the diff.
#   · IMPORT CLOSURE (THE SMALL RUN, 2026-07-14): a file imported by a frozen
#     file is FROZEN, transitively — a frozen file is only as frozen as its
#     dependencies. The criterion is objective, never taste. The 17 files the
#     closure added: the core types, id-minting, lineage, shape/packets, the
#     level3 tower (gate · orientation · w1 · homology · link extractor ·
#     faceIdentification), dualization, surfaceDual, seeds, the primitive
#     catalogue, and the written-form model.
#   · NO NUL BYTES (THE SMALL RUN, 2026-07-14): no frozen file may contain a
#     raw NUL byte — a NUL makes greps treat the file as BINARY and silently
#     skip it, so every content audit of it becomes a false negative that
#     looks exactly like a pass. The checker FAILS on a NUL (`nulled`).
#   · COMPLETENESS: every .ts/.tsx under src/lib, src/playground,
#     src/manuscript, src/types (types joined 2026-07-14 — it was a blind spot
#     in the blind-spot check) is either FROZEN (hashed below) or NOT_FROZEN
#     (named below, with a reason). Anything else is `unlisted` and FAILS
#     every witness — a new engine file can never again be silently unguarded.
#
# Audit rule: in any commit touching a frozen file, confirm exactly the
# sanctioned file’s hash line moved — nothing else.
