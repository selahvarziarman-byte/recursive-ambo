## 0. The reframe (de-bloating the naming/semantic layer)

For EVERY generated site, the minor campaign produces one PACKET:

```txt
PACKET(site) = {
  geometry/ambo : genealogy (parents, generation, operation), location, local triad (J; A, B), adjacency/relations
  witnesses     : geometry · birth-law(atomic) · field("no pressure", honest) · lineage · ambiguity
                  [Trison §1.1: Trisonized Midwife is ONE witness among others]
  EXCAVATION PROMPT : the fixed Trisonized Midwife frame, filled with the labels the human
                      has ALREADY placed on neighbouring sites
  naming decision   : the human's answer (X) with status — accepted / ambiguous / unsupported / candidate-not-final
}
```

The EXCAVATION PROMPT is the **fixed optimized frame** (Trison §8 output format / §16 method card) — a *search vector, not a guess*. Given a site's local triad (J = projection/opposite vertex; A, B = parents), it poses, in fixed order:

```txt
radix completions  J⊕A=Ω_A , J⊕B=Ω_B   ("what world appears when J completes with each parent?")
completion duality Ω_A ↔ Ω_B            ("shared axis? difference? what must be preserved?")
loop horizon       Λ                     ("what smaller/operational horizon preserves the duality without becoming either?")
child              X = Λ ⊖ J             ("what concept complements J into Λ — i.e. can dwell here?")
residuals          ρ_A=A⊖X , ρ_B=B⊖X     ("what do the parents still hold that the child does not?")
verdict            accept / ambiguous / unsupported
```

The *variables* are the already-placed neighbour labels; the *question* is "what concept can dwell at this site, given these relations to the named concepts around it?" (Worked example, Trison §11.1: J=Truth, A=Beauty, B=Unity → Λ=intelligible appearance → **X=Form**.)

NOTE — two distinct "semantics": (1) **naming** semantics = the excavation prompt (this campaign); (2) the topological-**ledger** interpreter (what a gluing/identification *means*) = a different, narrower thing downstream of the MAJOR campaign. The bloat was conflating them. Only (1) lives here.
