# 0014 — Kill-results become where-tests; expansion over minimalism

Sovereign-directed 2026-06-27, exemplified by the witness reframe (the field's "hollow" was **domain-dependence**, mothership-verified). A recalibration of the build posture for the **expansion phase** — the practical core is built; now we make the complex richer.

## The where-test law
A **kill / null / hollow** result is **never an endpoint.** It is converted into a **where-test**: *under what domain, condition, or enrichment does it fire?* "X is hollow" is incomplete until it is answered "hollow **where** — and where does it fire?"

Canonical worked example: "their field is hollow" was true only on a **simply-connected** domain (the cuboctahedron, χ=2 = S², H₁=0). Converted to a where-test, the answer is "it fires on a **w₁=1 cycle**" — the same connection reads holonomy −1 (verified). The null was a domain, not a death.

## Expansion over minimalism
The **practical core is built** (the topological module, the five necessities, the enablers). Minimalism — anti-monster, build-nothing-you-don't-need — was the right discipline *for building the core*, and the core is done. The mandate is now to **make the complex richer**: seize structural possibilities, lift the complex into richer carriers (the vector frame, the connection, the witness), rather than minimize. **Minimalism is no longer the default gate.**

## The rigor that remains (this is not "anything goes")
Richness is pursued through **falsifiable where-tests** — pre-registered, blinded, cross-office, honesty-budgeted (`#knobs ≤ #orbits`) — never through unfalsifiable inflation. "Seize richness" means *search harder for where the real structure fires, and gate it with a real test* — not *canonize beautiful things.* The where-test is **both** the expansion engine **and** the rigor: it is falsifiable. The discipline does not loosen; it **relocates** — from minimalism-as-gatekeeper to the where-test as the real question.

## Consequence for the seats
- **Researcher:** a null is a new where-test to design, not a kill to rule. (Cures the kill-bias.)
- **Mothership:** rule *"where does it fire?"*, not *"is it real? [kill if not]."* The skeptic posture **gates** the where-test (seal, blind, cross-office); it does not **foreclose** the search.
- The kill-bias that produced the field's "hollow" mis-ruling — ruling from our side of the wall, never reading the substrate, treating a simply-connected domain as a dead field — is the failure mode this ADR exists to prevent.
