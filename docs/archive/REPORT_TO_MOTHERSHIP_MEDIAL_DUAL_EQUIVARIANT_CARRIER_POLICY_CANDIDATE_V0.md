## 3. Root of the idea

Let the tetra primal labels be:

```txt
A, B, C, D
```

The first Ambo core produces six unordered edge children:

```txt
AB, AC, AD, BC, BD, CD
```

The second/core birth, equivalently octa G1, produces twelve medial sites. These twelve sites are not arbitrary. They are naturally identifiable as ordered flag / root tokens:

```txt
A→B, A→C, A→D
B→A, B→C, B→D
C→A, C→B, C→D
D→A, D→B, D→C
```

The interpretation is:

```txt
shared primal vertex → omitted primal vertex
```

Example:

```txt
AC and AD share A.
They omit B.
The resulting medial site is A→B.
```

This is the A3 root pattern:

```txt
α_ij = ε_i - ε_j, i ≠ j
```

with S4 acting by relabeling the four primal indices.

This matters because the old Fano C0 carrier table already contained twelve ordered lifts:

```txt
A·B, B·A, A·C, C·A, ...
```

The twelve cuboctahedral flag carriers match that latent ordered-lift layer.

Thus the new hypothesis:

```txt
Tetra G1 displayed the six unordered edge tokens.
Tetra G2-core unfolds the twelve ordered/flag lift tokens that were already latent in C0.
```

This is the bridge between the Fano-octonionic local chart and the A3/S4 medial-root skeleton.

## 4. Preliminary Stage-A discriminator

A standalone mathematical discriminator was run outside the repo. It does not certify app integration. It tests only the finite combinatorial/octonionic core.

### 4.1 A3 flag recovery

Result:

```txt
PASS, but non-discriminating.
```

The tetra G2-core / octa G1 hub gives exactly twelve ordered flag carriers.

This supports the A3/S4 medial-root skeleton, but it does not distinguish octonions from A3 incidence. A3 already predicts the 12 flags.

### 4.2 Bare signed-lift quotient-loss

Using the canonical Fano assignment:

```txt
A = e1
B = e2
C = e4
D = e7
```

The twelve flags collapse pairwise as bare signed octonion lifts:

```txt
A→B = +e3      C→D = +e3
B→A = -e3      D→C = -e3

A→C = +e5      D→B = +e5
C→A = -e5      B→D = -e5

A→D = +e6      B→C = +e6
D→A = -e6      C→B = -e6
```

Result:

```txt
Bare signed octonion unit is insufficient.
```

A carrier cannot be only `+e3`, `-e3`, etc. If octonions survive, they survive as a fiber attached to an incidence/flag token, not as bare units alone.

### 4.3 Triangle multiplication closure

The cuboctahedral flag graph has triangular faces. For every outgoing or incoming flag triangle, Fano signed-lift multiplication closes onto the third flag's carrier ray up to sign.

Example:

```txt
A→B = +e3
A→C = +e5
A→D = +e6

(+e3)(+e5) = -e6
```

Result under the canonical quadrangle:

```txt
48 / 48 ordered triangle products close onto ± the third flag.
```

Result under all valid Fano complete quadrangle labelings:

```txt
168 / 168 valid quadrangle labelings pass without triangle-closure failure.
```

Here `168 = 7 complete quadrangles × 24 labelings`.

This result is discriminating. A3 incidence predicts that these triples are triangles, but not the Fano multiplication closure pattern.

### 4.4 Square-cycle holonomy

The cuboctahedral flag graph has six square cycles.

For each square cycle, the left-associated product of the four Fano signed lifts around the cycle was computed. All cyclic rotations and reverse orientations were also checked.

Result under the canonical quadrangle:

```txt
all 6 square cycles produce +1
all rotations and reverse orientations also produce +1
```

Result under all valid Fano complete quadrangle labelings:

```txt
168 / 168 valid quadrangle labelings pass without square-holonomy failure.
```

This is strong evidence that the Fano-octonionic layer is doing more than labeling A3 incidence.

### 4.5 Fano gauge / quadrangle robustness

The test did not only use the hand-picked quadrangle `{e1,e2,e4,e7}`.

It enumerated all seven Fano complete quadrangles, and all 24 labelings of each quadrangle.

Result:

```txt
no quotient-loss anomaly;
no triangle-closure failure;
no square-holonomy failure.
```

This weakens the suspicion that the original quadrangle was only hand-fitted.
