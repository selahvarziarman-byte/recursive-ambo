## 1. The project in one page

PlatonicEngine is a geometric-semantic transformation workspace.

It begins with polyhedral geometry, but its true subject is intelligibility after transformation. A transformation operation should not merely create new geometry. It should preserve enough structure for later inspection: what existed, what was generated, what became a child, what lineages were created, what relations now exist, what field arises over the current source-domain, what local birth-law is present, and eventually how named material may move into another process space without false identity claims.

The long horizon contains several layers:

```txt
shape and generation
inspection and relation
dual/correspondence and semantic duality
packet/naming support
field / wave interference
atomic local birth-law
later semantic-topological process space
possible conceptual-cartographic organization
```

These are not meant to become rival systems. They are supposed to fold into one framework of intelligible transformation.

The current pivot says that this folding must be proven first in one concrete event:

```txt
four primal concepts inhabit a tetrahedron
-> one Ambo operation creates generated child sites
-> the system helps the human read those sites
-> the human attempts to name what can dwell there
```

This is called the proving event.

The first criterion of progress is not how many field candidates, markers, routes, gates, loops, regions, or reports exist. The first criterion is:

```txt
Does the generated event let the human understand something they could not understand before?
```
