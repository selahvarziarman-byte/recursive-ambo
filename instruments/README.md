# instruments/ — build a throwaway probe to KNOW

**This directory is gitignored. Nothing in it ships. Only this README is tracked.**

## The rule it enforces

> ### **An office may build an INSTRUMENT to KNOW. It may not build the PRODUCT.**
> — mothership, 2026-07-15

- **Instrument** = a throwaway probe, **outside the app**, never in the shipped build. Its output is a **RULING with the run attached** — never code to merge. **Build them freely, and build them BEFORE you spec.**
- **Product** = anything that ships. That still goes coder → engineer audit → seal → mothership co-ratification → Arman commits. **The seat map holds where it matters.**

## Why this directory exists

The rule was ratified, then lived only in a letter — so instruments piled up untracked at the repo root, where they were noise in every `git status`, one `git add .` away from shipping, and one import away from arming the untracked-imports guard (*no tracked file may import an untracked file*). **A doctrine you cannot enforce is a doctrine you are remembering, not running.**

## The standard (it binds every seat, including the mothership)

> ### **Any load-bearing substrate claim carries its EXECUTION, or it is not a ground.**

The two failure shapes this campaign keeps paying for, both covered by **Clause 1** (*a seal must EXECUTE the mechanism it claims to witness*), extended to routing claims:

- **a grep where an execution was owed** — the tower entered by an import the grep didn't match;
- **an assertion from a variable's NAME** — `deckDet(g) < 0` reads "mirrored", so it was called the flip. It isn't.

**And check your check:** `tower.w1` is an object, not a scalar — a `=== 1` test on it silently reads nothing and reports zero.

## Conventions

- **Name for the question**, not the run: `walk_bug.ts`, `mode_vs_fit.ts`, `three_strata.ts`.
- **Delete freely.** Nothing here is owed to anyone. If a result matters, it belongs in a **ruling** (with the run attached) or a **witness leg in the repo** — *a certificate that lives in someone's scratchpad is not a certificate.*
- **Never import an instrument from tracked code.** That is the guard's fuse, and it is the line between an instrument and the product.
- Root-level scratch that pre-dates this directory is ignored where it lies — **move yours here when convenient; nobody will move another seat's files for them.**
