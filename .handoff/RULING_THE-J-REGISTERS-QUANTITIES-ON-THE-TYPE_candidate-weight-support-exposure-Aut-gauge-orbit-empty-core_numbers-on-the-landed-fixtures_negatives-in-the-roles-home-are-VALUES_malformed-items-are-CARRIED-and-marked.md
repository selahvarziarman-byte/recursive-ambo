## 1 · THE DEFINITIONS, on `ConceptSpace` and `EdgeIdentification`

**The record of a cast** (`record`, `load` :41–61) — the KNOWN tuples of both homes as one map: `(σ, terms) ↦ polarity` from `relations`, and each role's categorical unary keys as `(K, (x,)) ↦ value` from `roles[].types`; `'UNKNOWN'` and absence are UNRECORDED. **A unary type lives in ONE home per cast**: a name that is both a `types` key and a signature type is the record declaring one type twice — a CONSISTENCY refusal, by name (§4).

**1 · CANDIDATE.** On two casts `X`, `Y` at the ends of an edge: **the SHARED SIGNATURE by name** (`tau_by_name` :63) is the set of type-names present in both with the SAME arity, plus the unary keys present on roles of both. **A name with two arities across the casts is NOT the same type** — not shared, NAMED in the register (*"`r` is arity 2 here and 3 there — not the same type"*), never refused. **A translation between differently-named types is τ given by the person** (`EdgeIdentification.types`; a fiat τ-pair must be arity-preserving — a mismatched arity is refused by construction); it is not offered by name. A **candidate** is a partial injection `j` of roles, **consistent** — no KNOWN CONFLICT: for every shared type and every tuple over `dom j`, if both sides know the tuple their values agree (`evaluate` :71–90 returns `None` on a conflict) — with **weight > 0**. Reflection both ways is what consistency IS: `X`'s known tuples are checked against `Y` and `Y`'s against `X`. ⇒ **`J = ∅` is NOT a candidate** (weight 0); it is the person's lawful CHOICE (*none taken*) and, when nothing else is offered, the EMPTY-CORE state (§1.6). The register offers, weight-ordered, **the candidates of full size** (`min(|R_X|, |R_Y|)`) at each weight from the top; among equal weights only the inclusion-maximal — a candidate less an UNSUPPORTED pair is the same candidate with the pair marked, not a second entry (`top_candidates` :102–135).

**2 · SUPPORT and WEIGHT.** An **agreement** is a tuple over `dom j` in a shared type that is KNOWN ON BOTH SIDES WITH THE SAME VALUE under `j` — **`does-not-hold` agreeing with `does-not-hold` IS an agreement** (confirmed: the three-valued discipline; a shared negative is content), and **a shared unary value IS an agreement** (both homes count; `evaluate` :78–85). `weight(j)` = the number of agreements. `support(j, x)` = the agreements whose `X`-tuple contains `x` (`:84`); a pair with support 0 is UNSUPPORTED — offered marked, never hidden.

**3 · EXPOSURE, UNRECORDED, and the opposite polarity.** Over `dom j` in the shared types: **exposure** = tuples known on exactly one side (`:80, :86–88`); **unrecorded** = known on neither (`:89`, arithmetic: `Σ |dom j|^arity − agree − exposed`). **The opposite polarity is a CONFLICT, and a candidate does not have one — by definition** (`:82`). ⇒ **Two counts on an offered candidate, never a third.** The third value exists only where the person ADDS a fiat pair that creates a conflict: the taken `J` then carries **each conflicting tuple as a mark, listed by name** (`fiat` pairs are visibly distinct; their conflicts are printed beside them, never folded into weight or exposure). So: *offered candidates print two counts; a fiat-extended `J` prints its conflicts by name.*

**4 · `|Aut|` and the tie.** `Aut(X)` (`aut` :92–100) = the permutations of `X`'s roles that map `X`'s WHOLE record to itself exactly (known ↦ known with the same value; unrecorded ↦ unrecorded) — the cast's own symmetries, on its full signature, never the shared reduct (a symmetry of the reduct alone would change what the candidate does to the unshared roles at the midpoint). **Two candidates are ONE candidate iff `j' = β ∘ j ∘ α⁻¹` for `α ∈ Aut(X)`, `β ∈ Aut(Y)`** — a GAUGE ORBIT (`:122–131`). **The sentence *"N candidates tied — this cast has N symmetries"* is true exactly when the tied set is ONE orbit and `Aut(Y)` acts trivially on it — the case of a cast against a copy of itself, where the top candidates ARE `Aut(X)`.** In general the true sentence is: *"N tied — k readings (gauge orbits); this cast has `|Aut(X)|` symmetries, that one `|Aut(Y)|`"* — and `k > 1` means genuinely different readings the person must choose between (the first face's `S1`/`S2` families were two orbits; `S2`/`S3` were one). The register prints orbits, not only ties.

## 2 · §0 — A NEGATIVE IN THE ROLES' HOME IS A VALUE
`roles[].types` holds CATEGORICAL unary types: `K: v` asserts `K(x) = v` and thereby denies every other value of `K`. **Its negative is another value** — `windowed: "NO"` is the negative of `windowed: "YES"` — never a polarity; `'UNKNOWN'` is unrecorded. Across an edge: same known value = agreement (counted in weight); different known values = conflict (the member-status refusal of the first face); one side unknown = exposure. **The both-homes contradiction the coder stopped on does not need a negative in the roles' home: a name declared in BOTH homes is itself the contradiction — the record states one type two ways — refused at the cast, by name**, the same class as a signature name with two arities. The loader's consistency check therefore spans the homes by checking that no name is in both, and the card's count (which already spans both) stays right because the names are disjoint.

## 3 · §2 — A MALFORMED ITEM: (b), CARRIED UNREAD ON THE WARRANT AND MARKED
A role without an id, a relation without a type or terms, a polarity that is neither value, an axiom without a sentence — **these are not items OF the structure** (they name no role, assert no tuple, state no sentence), so taking the structure whole without them is not a partial take; **but they are bytes the person wrote, and bytes are carried.** ⇒ **(b):** the item is carried unread on the warrant, by index, and the mark names it (*"relation 3: polarity `hold` is neither value — not taken; carried"*). Erased nothing; fabricated nothing (the device may not guess the polarity); marked what the substrate does not determinately hold — the lift law's three clauses, in order. **(a)** would refuse a whole structure for junk beside it — the contradiction rule, mis-applied: a contradiction is INSIDE the structure's content, a malformed item is not. **(c)** — mark and drop — erases the bytes. The loader's present behaviour (`:86, :119, :124, :142`) is (c) by a hair: it marks and does not carry; the one-line rider is *carry the raw item on the warrant beside its mark.* The same rider covers closure and arity breaks, which the loader already carries and marks — consistent with the mold: *an unresolved foreign term is the structural signature of a missing role.*
